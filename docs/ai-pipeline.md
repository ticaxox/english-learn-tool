# AI 链路设计（规划中）

- 事实基线：`caa731c`
- 产品来源：`AI英语学习工具_v1.1_落地开发文档.md`
- 当前实现状态：**未实现**
- 当前代码中没有 `ai_providers` 表、AI provider 适配器、提示词管理、额度账本、题目或评分任务
- 容器/CI 基础已在 `a5bf49b` / run `39801657963` 验证，但不包含任何 AI 业务实现

本文保留后续技术文档和实现所需的结构。任何 AI 能力在真实 provider、数据库任务、校验器、额度控制和测试到位前，不得写成“已完成”。

## 1. 目标分层

```text
业务请求
  │
  ├── 后端计算合法上下文和 JSON Schema
  │
  ├── ai_jobs 持久化任务状态
  │
  ├── ARQ worker 调用 OpenAI 兼容 provider
  │
  ├── Pydantic + 业务校验器
  │       ├── JSON 修复（最多 1 次）
  │       └── 逻辑重生成（总尝试最多 3 次）
  │
  └── 事务性保存完整结果；失败不保存半成品
```

AI 不是数据库权限主体。所有写入由后端受控服务完成。

## 2. 结构化生成与校验

### 固定链路

1. 后端选择合法词条、题目类型、难度、数量和任务模板。
2. 向 provider 提供 JSON Schema 和数据不是指令的安全提示。
3. 解析模型响应。
4. 使用 Pydantic v2 校验字段、类型、数量和枚举。
5. 执行业务逻辑校验。
6. JSON 非法时最多修复 1 次。
7. 逻辑仍非法时重生成，整个逻辑任务最多 3 次尝试。
8. 最终失败写入失败状态并释放额度预留。

### 业务校验示例

- 选择题正确选项必须存在且唯一。
- 阅读文章不少于 200 个英文词，问题数匹配要求。
- 词书题目只能引用后端提供的合法实体 ID。
- 主观题维度分和总分必须在合法范围内。
- 挑战地图必须覆盖当天完整新词目标，终点挑战必须位于最后。
- 挑战节点数量和可选支线数量符合约束。
- 提交前答案、解析、参考内容必须被 API 序列化层剥离。

### 重试边界

- 普通网络错误、429、5xx：同一逻辑尝试最多自动重试 2 次，指数退避。
- JSON 修复：最多 1 次。
- 逻辑生成：总尝试最多 3 次。
- 失败请求不扣逻辑额度，不返回部分题目或部分评分。
- 生产环境不得用静态题目、假评分或模拟 AI 作为兜底。

## 3. AI 练习

规划中的四种题型：

| 题型 | 判分 | 目标要求 |
|---|---|---|
| 填空 | 后端客观判分 | 完整句子、4 个唯一选项、目标词 |
| 阅读 | 后端客观判分 | 每篇不少于 200 词，每篇 3–5 问 |
| 翻译 | AI 主观评分 | 英译中、中译英、混合 |
| 作文 | AI 主观评分 | 目标词数 50–300，可提前提交 |

统一要求：

- 百分制，维度分与总分合法。
- 低于 60 分的主观题进入错题本。
- 草稿保存使用版本号防止旧标签页覆盖。
- 提交前答案不可通过 API 或错误信息泄露。
- 提交使用 `Idempotency-Key`，重复请求不得重复判分或扣额度。
- AI 失败不生成默认分数或假的参考内容。

## 4. AI 教练

### 允许读取

- 当前页面和实体 ID。
- 用户选中的词书、练习会话和未提交草稿。
- 近期学习事件、今日任务、FSRS 概况和挑战进度。
- 用户学习档案和主动输入内容。

### 禁止读取或执行

- 其他用户数据、API Key、密码、刷新令牌。
- 删除用户、词书、练习记录或教练对话。
- 修改密码、API Key、管理员配置。
- 绕过额度、权限或代替用户提交未完成答案。

### SSE 事件

规划事件：

- `message.delta`
- `action.applied`
- `usage`
- `done`
- `error`

所有自动写入必须走受控 action schema，生成回执，并在 24 小时内支持撤销。撤销前重新校验状态；若状态已变化，返回可解释冲突，不强行回滚。

## 5. 每日挑战编排

后端先计算：

- 今日新词目标和 ID。
- 快照到期词 ID。
- 合法词条和任务模板。
- 练习类型、难度和额度余量。
- 用户目标时长、当前完成情况和最近挑战表现。

AI 只决定：

- 节点组合与顺序。
- 新词如何拆入节点。
- 是否加入一个可选支线。
- 练习参数、预计时长和文案。

AI 不得减少新词量、虚构实体或生成第二套学习量。地图生成成功后当天固定；失败时显示失败和重试，不使用伪造的替代地图。

## 6. 额度与异步任务

规划默认额度：

- AI 教练：每天 100 条消息。
- 结构化题目生成：每天 20 次。
- 主观题评分：每天 50 题。
- 每人最多 2 个并发 AI 任务。

`ai_usage_ledger` 记录 reserve、consume、release；数据库任务状态是权威，Redis 只负责队列和短期并发控制。worker 崩溃恢复不得重复产生付费调用。
