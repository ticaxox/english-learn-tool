## 3. 分镜脚本

### 0:00–0:30｜问题与定位

画面：标题页或产品首页。

旁白：

> 这是一个面向学校、企业培训项目和学习组织内部成员的私有英语学习平台。它把词书、FSRS 复习、AI 练习、教练、每日闯关和组织看板放在同一个真实闭环里。

### 0:30–1:10｜架构与工程证据

画面：`docs/architecture.md` 拓扑图；浏览器展示 GitHub Actions run 和 5/5 作业。

旁白：

> 系统采用模块化单体。Vue 前端通过 API 访问 FastAPI，PostgreSQL 保存业务真相，Redis 和 ARQ 负责队列，worker 和 scheduler 共享私有词书卷。CI 已验证七个容器服务、空库迁移、非 root 和回环端口；A40 还在临时 HTTP IP 预览上验证了健康、登录、SSE 和备份恢复。

边界：这是临时 HTTP IP 预览，不是稳定 HTTPS，也不是最终 MVP PASS。

### 1:10–2:10｜管理员配置

画面：

1. 打开 `http://23.94.141.170:18080`，登录 `demo_admin`（密码从 A40 ACL 本地凭据文件获取）。
2. 成员管理：3 个合成成员。
3. 词书列表：Aurora 20 词组织词书。
4. 创建一个合成成员或展示 CSV 预览（若时间允许）。

旁白：

> 管理员可以创建成员、导入词书、保护最后一个管理员，但看不到成员答题正文、草稿、教练对话或私有词书正文。

### 2:10–2:50｜AI 平台

画面：AI provider 列表、Key 掩码、连接检查、提示词页面、用量。

旁白：

> provider Key 在服务端加密，接口只返回掩码；提示词修改只影响未来任务；额度和并发由数据库账本约束。模型失败会保留真实错误，不生成假题。

### 2:50–3:30｜管理员看板

画面：组织看板、3 个活跃成员、分组隐私、聚合指标。

旁白：

> 看板只展示聚合指标。低于最小分组时会抑制分组明细，避免从聚合反推个人隐私。

### 3:30–4:20｜成员计划与 FSRS

画面：

1. 登录 `demo_member`。
2. 今日计划：新词/到期复习。
3. 记忆训练：翻卡、选择或拼写。
4. 刷新后仍能看到服务端状态。

旁白：

> FSRS 只在后端计算复习时间和卡片状态。客户端提交动作和答案，不提交稳定性、难度或到期时间。

### 4:20–5:20｜四类 AI 练习

画面：

1. `/practice` 创建填空练习。
2. 提交前页面没有正确选项/解析。
3. 提交后显示 66.67 分、解析和错题。
4. 打开练习记录和错题本。
5. 可切到失败态：provider 不可用，显示错误码和 Request ID。

旁白：

> 练习生成、草稿、提交和评分都是持久任务。提交前 API 不返回答案；失败时不使用静态假题兜底。

### 5:20–6:00｜AI 教练

画面：

1. 打开 `/coach` 对话。
2. 展示流式回复和 `adjust_daily_plan` receipt。
3. 展示撤销入口和前后状态。

旁白：

> 教练只能读取合法上下文，自动写入必须走受控 action。回执保存前后状态，并支持 24 小时内撤销；冲突时不会强行回滚。

### 6:00–6:45｜每日闯关

画面：

1. 打开 `/challenges`。
2. 展示 5 个节点：复习、新词、词义训练、AI 练习、BOSS。
3. 展示 2 个已完成、3 个未完成状态。
4. 打开已完成 BOSS 结果，刷新后仍可见。

旁白：

> 传统学习与挑战共享同一份计划事实，AI 只编排节点，不减少今日新词目标，也不虚构实体。

### 6:45–7:20｜通知与失败态

画面：通知收件箱、偏好/DND、失败态 Request ID。

旁白：

> 通知按类别、DND 和 dedupe key 处理；AI 完成/失败保留例外。失败界面展示真实错误，不伪装成功。

### 7:20–7:50｜总结

画面：技术文档创新点 + 已知限制。

旁白：

> 我们的创新点是 FSRS 与 AI 决策分离、结构化 AI 合同、受控可撤销教练和隐私优先看板。代码内硬化、v0.1.0 发布和临时 HTTP 预览已通过，但稳定 HTTPS、最终视频和最终 MVP 验收仍未完成，完整 MVP 仍为 FAIL / NOT_READY。
