# 演示视频大纲（待录制）

- 当前状态：脚本结构已建立，完整产品画面未具备
- 目标：5–8 分钟、1080p 以上、普通话真实录屏
- 基线：`c3b2a50` 只能录制工程基线段落，不能冒充完整产品演示

## 1. 录制前门禁

正式录制前必须满足：

- 使用合成组织和合成学习数据。
- 真实 API、数据库和 AI provider 可运行。
- 认证、词书、FSRS、练习、教练和挑战至少完成一次 E2E。
- Docker/公网演示结论有 T-SHIP 证据。
- 浏览器、终端和录屏素材不含 Secret、真实成员数据或服务器接入信息。
- 失败态可重复演示，且 UI 不伪造成功结果。

未满足时只能录制“工程基线说明”，标题不得写成完整产品演示。

## 2. 推荐时间轴

| 时间 | 内容 | 画面/证据 |
|---|---|---|
| 0:00–0:35 | 问题、目标用户、价值主张 | 产品定位页，简洁说明组织内部学习闭环 |
| 0:35–1:10 | 架构与 AI 技术链路 | 模块化单体、FSRS 与 AI 决策分离 |
| 1:10–2:00 | 管理员创建成员、配置 provider | 真实管理员操作与合成成员 |
| 2:00–3:10 | 导入/激活词书，翻卡、选择、拼写 | 真实词书、真实 FSRS 变化 |
| 3:10–4:20 | AI 生成并评分练习 | 填空/阅读或作文、提交后解析与建议 |
| 4:20–5:20 | AI 教练读取上下文、调整计划 | 真实对话、action receipt、24h 撤销 |
| 5:20–6:40 | 每日闯关地图、节点、BOSS、次日反馈 | 真实地图、节点同步、结果上下文 |
| 6:40–7:30 | 安全边界、失败态、指标与总结 | 管理员看不到隐私正文；容器/CI 证据 |

时间可压缩到 5–8 分钟，但不得删掉真实 AI、FSRS、隐私边界和容器证据。

## 3. 当前可先行录制的工程片段

可以作为内部工程记录：

1. 显示提交 `c3b2a50` 和干净工作树。
2. 启动后端并访问 `/health/live`、`/health/ready`。
3. 访问 `/api/v1` 和 OpenAPI。
4. 启动前端，展示 `/api` 代理和统一错误状态。
5. 运行后端/前端测试与构建命令。

该片段不能用于宣称认证、业务功能、AI、容器或比赛 MVP 已完成。

## 4. 画面与讲解规则

- 使用真实浏览器，不使用纯 PPT 冒充产品操作。
- 对敏感字段做遮挡，但不得遮挡关键功能或测试结论。
- 讲解区分“已实现”“规划中”“待验证”。
- 失败演示应保留真实错误、Request ID 和重试，不切换 mock。
- 提交前的测试输出、镜像 digest 和 Git SHA 应可读但不得泄露凭据。
- 视频描述中注明合成数据、演示环境和已知限制。

## 5. 录制后检查

- 视频长度 5–8 分钟，分辨率不低于 1080p。
- 音频清晰，普通话讲解完整。
- 没有真实 API Key、密码、私钥、服务器地址或成员隐私。
- 功能与当前提交/镜像一致。
- 失败片段与成功片段比例合理，不掩盖限制。
- 保留录制日期、提交 SHA、镜像 digest 和演示数据版本。
