# 来源、许可证与素材边界

- 版本：T-DOC-002 / 2026-10-24
- 状态：来源边界已说明；**源代码许可证待 A00 决策**
- 用途：比赛提交前的数据、依赖和素材核对

## 1. 源代码许可证

当前仓库未添加开源 `LICENSE` 文件，也没有由 A00 批准的开源/公开授权文本。仓库当前是 Private 比赛项目；公开提交前必须由 A00 明确：

1. 代码是否公开；
2. 使用何种许可证（如 MIT/Apache-2.0/专有）；
3. 是否允许复制、修改、再分发；
4. 第三方依赖和素材的兼容性。

在 A00 决策前，不得自行添加许可证或宣称项目已开源。当前提交清单把许可证保留为 `TODO`。

## 2. 第三方依赖

项目使用的主要第三方依赖包括：

- FastAPI、Pydantic、SQLAlchemy、Alembic、asyncpg、Redis/ARQ。
- Vue 3、Vite、Pinia、Vue Router、Vitest。
- PostgreSQL 16、Redis 7、Docker/Compose 运行环境。
- FSRS Python 包、ReportLab、PyJWT、Argon2 等。

这些依赖保留各自的许可证和版权；本项目不重新授权其代码。提交前应保留 lockfile、依赖清单和必要的许可证声明。

## 3. 演示数据来源

- `seed_demo_data.py` 中的词条、释义、例句、账号、练习、对话和通知均为本项目编写的合成数据。
- 不使用第三方受版权保护的词书正文、真实组织成员、真实对话或私有学习数据。
- 合成词书名称、账号和 ID 带 `demo` 标记，便于识别和清理。
- 演示密码不进入仓库，由运行环境或受控渠道提供。

## 4. 截图与视频

- `docs/competition/screenshots/` 的截图来自本项目 T-QA-004 合成数据浏览器验收。
- 截图不含真实服务器地址、Token、Key、真实成员或私有正文。
- 截图不是公网部署截图，也不是最终比赛视频。
- 最终视频必须使用合成数据；不得使用来源不明的背景音乐、字体、图片或视频素材。

## 5. 字体、图标与素材

当前文档/前端未引入需要额外授权的比赛媒体素材。若后续添加字体、图标、图片、背景音乐或模板，必须：

1. 记录来源、许可证和获取日期；
2. 保存可追溯链接或授权文本；
3. 不使用来源不明素材；
4. 在视频/文档中保留必要 attribution；
5. 由 A00/A50 在提交前复核。
