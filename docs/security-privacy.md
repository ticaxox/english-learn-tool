## 1. 身份与会话

- 密码使用 Argon2id 哈希。
- Access Token 短时 JWT，只保存在前端内存。
- Refresh Token 30 天、随机、数据库只存哈希，放在 HttpOnly Cookie 并轮换。
- Refresh family 重放检测会撤销整个 family。
- Cookie 写请求校验 Origin 与双提交 CSRF Token。
- 管理员重置密码、停用、删除或改密会撤销对应 Refresh 会话。
- 最后一个启用管理员不可删除、停用或降级。
- 登录失败统一提示，避免用户名枚举。

## 2. 授权与隐私

| 数据 | 成员本人 | 管理员 |
|---|---|---|
| 账号状态、学习档案 | 可读/可改 | 可读必要管理字段 |
| 私有词书正文 | 可读本人 | 不可读 |
| 答题、作文、翻译正文 | 可读本人 | 不可读 |
| 未提交草稿 | 可读本人 | 不可读 |
| AI 教练标题/消息/action 正文 | 可读本人 | 不可读 |
| 学习时长、完成率、AI 用量 | 可读本人 | 可读聚合 |
| 组织看板分组 | 不适用 | 低于最小分组时抑制 |

前端路由守卫只负责体验，后端服务层必须再次校验角色和资源所有权。

## 3. AI 安全

- API Key 服务端加密，接口只返回掩码。
- Base URL 校验协议和主机，阻止云元数据地址、非法内网和重定向绕过。
- 提示词与模型输出视为不可信输入，必须经过 Pydantic 和业务校验。
- 题目提交前不返回答案、解析或参考内容。
- 模型 Markdown 不作为未净化 HTML 注入。
- 教练自动写入必须走受控 action，保存回执并支持撤销。
- 额度、并发和任务状态由数据库账本/任务状态约束。

## 4. 上传、导出与日志

- 词书上传使用随机文件名、大小/行数/解析时间限制。
- 路径穿越文件名返回 422；导出下载使用短期授权，不暴露可枚举公开路径。
- 日志不记录密码、明文令牌、Key、主密钥、完整答案、教练全文或上传正文。
- 审计记录登录、管理员操作和 AI action，但只保存必要上下文。
- Request ID 贯穿响应、错误和日志。
