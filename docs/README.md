## 更新规则

1. 先核对代码、命令输出或证据，再改文档；文档不得领先于代码。
2. 数字类事实（迁移 head、表数、路径数、测试数）必须能在当前 `main` 上复现。
3. 代码行为变化后，同步改本索引、对应专题文档与 `fact-check.md`。
4. 未完成项明确标注，不用计划、占位值或旧截图冒充完成。
5. 不写入真实用户数据、密钥或生产连接串。
