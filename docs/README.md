# 文档索引

本目录记录产品目标、当前代码事实、验证证据和后续交付结构。产品蓝图中的规划能力不能因为写入文档而被视为已实现。

## 状态标记

| 标记 | 含义 |
|---|---|
| **已验证** | 在指定提交上通过代码定位或实际命令得到证据。 |
| **已实现，待联调** | 代码存在且有单元/组件测试，但尚未完成跨层真实联调。 |
| **规划中** | 产品基线要求，当前仓库尚未实现。 |
| **待 T-SHIP 验证** | 依赖容器、Compose、CI 或部署任务，当前不得声明通过。 |
| **待补充** | 正式参数或比赛材料尚未提供，不得臆造。 |

## 更新规则

1. 先核对代码、命令输出或任务证据，再修改状态。
2. 新功能文档必须同时写明实现状态、入口、验证命令和未覆盖范围。
3. 代码行为变化后，更新 `fact-check.md` 和对应专题文档。
4. 容器、CI 和公网部署完成后，必须回读 A40 的详细证据才能升级状态。
5. 不得在文档中写入真实成员数据、密钥、生产连接串或敏感接入信息。
